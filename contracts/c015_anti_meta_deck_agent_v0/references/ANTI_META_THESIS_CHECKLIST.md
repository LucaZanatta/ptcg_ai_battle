# Anti-meta thesis checklist

The chosen branch must answer all of these in concrete terms:

1. **Target:** Which single current public archetype or strategy is the primary target?
2. **Counter mechanisms:** Which two deck mechanics create the expected advantage?
3. **Automation fit:** Why can deterministic rules execute those mechanics reliably?
4. **Complementarity:** Which c014 weakness or matchup does this branch cover?
5. **Distinctness:** Is the deck list and core game plan materially different from c014?
6. **Feasibility:** Can a coherent v0 be implemented, packaged, and tested in one day?
7. **Falsifier:** What observed local behavior would show that the thesis is not being executed?

Required one-sentence form:

> This deck should beat **TARGET X** because **MECHANISM A** and **MECHANISM B**, while covering c014's weakness to **Y**.

The thesis may be provisional, but it may not be vague. “Different deck,” “more flexible,” or “better matchup spread” are not valid counter mechanisms.

# Public mining checklist

This checklist records leads, not conclusions. Every item must be freshly verified.

## Official/current facts

- competition page and slug
- simulation deadline and Europe/Rome conversion
- submission-per-day rule
- package structure and runtime/timeout rules
- permitted public data/code rules
- current submission status and leaderboard/public-rating evidence

## Public evidence targets

- latest public top-agent episode datasets
- latest public notebooks and discussion threads
- deck lists used by strong public agents
- rule-agent code or pseudocode
- prize/resource tracking implementations
- timeouts, invalid-action, and packaging failure discussions
- current archetype distribution and counters

## Starting leads to verify

- Starmie/Froslass rule-based agent
- prize-card/resource tracking notebook
- Mega Gengar alternative strategy
- top-agent episode datasets
- decision-comparison and ladder-meta analysis notebooks

These leads came from an earlier handoff and may be stale, incomplete, renamed, or superseded.

## Evidence quality labels

Use one label for every claim:

- `OFFICIAL_CURRENT`
- `PUBLIC_REPRODUCIBLE`
- `PUBLIC_REPORTED`
- `INFERENCE`
- `STALE_OR_UNVERIFIED`

Deck selection must not rely primarily on `INFERENCE` or `STALE_OR_UNVERIFIED` evidence.

# Technical Risks — Ranked by Severity

| # | Severity | Risk | Evidence / basis | Mitigation direction |
|---|----------|------|------------------|----------------------|
| 1 | **HIGH** | **Closed-source binary engine.** The entire game logic lives in `libcg.so` (x86-64 ELF, no source). We cannot inspect rules, and there is no Windows `cg.dll`. If the Kaggle runner arch/ABI differs, or the `.so` is not shipped with the submission, agents fail silently. | `sim.py` loads `libcg.so` via `ctypes`; `cg.dll` referenced but absent. | Treat the engine as a black box; pin to the `cabt` env; verify the submission bundle includes the `.so` / relies on the runner-provided env. |
| 2 | **HIGH** | **Legal-action correctness is unproven.** The baseline only does `random.sample(...)` over `option`; it never validates `minCount`/`maxCount` semantics per `SelectContext` (~28 contexts). A malformed selection raises `IndexError`/`ValueError` in `battle_select` and forfeits the game. | `game.py:battle_select` raises on bad indices; `SelectContext` enum has ~28 members with differing count rules. | Build a deterministic legal-action fallback (natural c001) with fixtures per `SelectContext`. |
| 3 | **MEDIUM** | **No episode/replay data captured.** There is no saved game log/replay corpus; all evidence is generated live. Any future learning/analysis contract must first produce and persist episodes. | No episode files in repo; `test_engine.py` discards `env.steps`. | Add an episode-capture contract before training work. |
| 4 | **MEDIUM** | **Deck is fixed and tiny (9 unique cards).** `deck.csv` has only 9 distinct IDs across 60 slots. Strategy generality and card-interaction coverage are limited; changing the deck is a flagged "major decision". | `sort -u deck.csv` → 9 IDs. | Keep deck fixed unless explicitly re-scoped; document card interactions from `EN_Card_Data.csv`. |
| 5 | **MEDIUM** | **Latency/compute budget for a real agent is untested.** Random baseline is ~0.09s/game, but Kaggle enforces per-step time limits. A search-based agent using `search_begin/step` could exceed them; the budget is not yet measured. | `baseline_metrics.json` measures random play only; `SearchStep` FFI exists but is unbenchmarked. | Benchmark `search_*` per-step latency before committing to a planning agent. |
| 6 | **LOW** | **Repo hygiene / fragile paths.** `test_engine.py` and `check.py` hard-code the absolute path `/home/luca/kaggle/ptcg_ai_battle`; `cg` is a symlink; `tmp.txt` (4.4M) and `check.py` are stray untracked files. Non-portable and confusing for teammates/CI. | `grep` of hard-coded paths; `git status` untracked list. | Parameterize paths; gitignore scratch files; document the `cg` symlink requirement. |
| 7 | **LOW** | **Large binary assets unversioned.** 306M of card PDFs + `.so` + `.venv` (1.4G) are untracked. Risk of accidental commit or loss. | `du -sh` of top-level entries. | Decide tracking policy (git-lfs vs external) explicitly. |

**Top 3:** (1) black-box engine portability, (2) unverified legal-action handling, (3) no persisted episode data.

# License and Reuse Policy

## Official MCGS source

The official competition page provides source download permission, but the archive's internal license terms must be audited.

Default policy:

- retrieve, inspect, hash and behaviorally map the source;
- do not copy source into a PTCG submission package unless license compatibility is explicitly established;
- prefer a clean PTCG port based on audited behavior and paper semantics when licensing is unclear;
- preserve attribution and source hashes in research artifacts;
- do not call a clean-room port line-for-line exact.

## ByteRL

Do not assume public source exists. Search first. If no verified complete author source is found, implement from primary papers and state clearly that fidelity is equation/architecture/control-flow fidelity, not source-code identity.

## Peter1591 repository

The repository declares GPL. It is deferred and must not be copied into c021 or a competition package.

## PTCG/public agents

Use only competition-permitted materials. Record author, URL, date, license/permission and hashes. Unclear-permission code may be used only as an external local reference when legally appropriate, not bundled into submissions.
